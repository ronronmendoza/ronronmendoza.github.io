# Ron-Ron Mendoza — Executive Portfolio

GitHub Pages-ready static portfolio. Video files are encoded as browser-compatible MP4 (H.264/AAC) with fast-start metadata.

## Important
Keep `index.html`, `style.css`, `script.js`, `videos/`, `video-posters/`, `images/`, `assets/`, and the PDF/XLSX files in the repository root. The HTML uses relative paths so the portfolio works on GitHub Pages, including project-site URLs.
